# Open Source Credits

Hello! If you're here for Fyra Stack credits for your open source project, you're in the right place!

To apply, simply open the [Issues](https://github.com/FyraStack/open-source-credits/issues) tab and fill out one of the form templates. We will get back to you as soon as we can.

> [!NOTE]
> Please note that we're only accepting requests from projects previously on DigitalOcean's discontinued Open Source Program.
> This is to make sure we can focus on projects that need to migrate off of DigitalOcean urgently.
> A more general request form will be made available in the near future.
